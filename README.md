# Stars

Animação de céu estrelado feita em CSS/JS puro — estrelas geradas dinamicamente com posição e brilho aleatórios.

## ✨ Funcionalidades

- Geração procedural de estrelas via CSS custom properties
- Animação de brilho (twinkle) suave e performática
